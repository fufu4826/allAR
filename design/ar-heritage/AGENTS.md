# Instructions for AI agents (Codex)

Read `README.md` in this folder fully before changing anything. The team workflow (how to start, how to hand work back) is in `docs/team/AI-GUIDE.md` at the repo root. It explains:
- that this folder is only the static design prototype (the real site is the `web/` folder of this repo);
- how its CSS and class names map into the real site;
- the 5 learning sites and their slugs and themes;
- decisions that are already made.

Key rules:
- Never rename existing CSS classes.
- Save every file as UTF-8 (Thai text).
- Don't treat `*-models.js` as real data.
- Add a line to README section 7 for every design change.
- Ask the project owner before changing anything listed in README section 5.
