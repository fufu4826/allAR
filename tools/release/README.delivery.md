# แหล่งเรียนรู้สกลนคร 3D

**Sakon Nakhon Learning Sites 3D**

เว็บไซต์แหล่งเรียนรู้และพิพิธภัณฑ์ท้องถิ่นจังหวัดสกลนครในรูปแบบออนไลน์เสมือนจริง นำเสนอโบราณวัตถุ ภูมิปัญญา และเรื่องราวของ 5 แหล่งเรียนรู้ ผ่านโมเดล 3 มิติ ระบบความจริงเสริม (AR) เสียงบรรยาย และวิดีทัศน์ เปิดให้ประชาชนเข้าชมได้ทุกอุปกรณ์โดยไม่ต้องติดตั้งแอปพลิเคชันหรือสมัครสมาชิก

พัฒนาภายใต้โครงการเพิ่มศักยภาพแหล่งเรียนรู้และพิพิธภัณฑ์ท้องถิ่นจังหวัดสกลนครในรูปแบบออนไลน์เสมือนจริง สถาบันภาษา ศิลปะและวัฒนธรรม มหาวิทยาลัยราชภัฏสกลนคร

## แหล่งเรียนรู้ในระบบ

1. อาสนวิหารอัครเทวดามีคาแอล ชุมชนบ้านท่าแร่
2. พิพิธภัณฑ์วัดกลางศรีเชียงใหม่ ชุมชนบ้านท่าวัดใต้
3. พิพิธภัณฑ์วัดมหาพรหมโพธิราช ชุมชนบ้านท่าวัดเหนือ
4. แหล่งเรียนรู้ชุมชนบ้านโนนหอม
5. ศูนย์ศึกษาการพัฒนาภูพานอันเนื่องมาจากพระราชดำริ

## ความสามารถของระบบ

**สำหรับผู้เข้าชม**
- แผนที่ 3 มิติของจังหวัดสกลนคร แสดงตำแหน่งแหล่งเรียนรู้ทั้ง 5 แห่ง พร้อมแผนที่ 2 มิติสำรอง
- หน้าแหล่งเรียนรู้ พร้อมเรื่องราว วิดีทัศน์แนะนำ และคลังชิ้นงานแยกหมวดหมู่
- หน้าชิ้นงาน แสดงโมเดล 3 มิติที่หมุนและซูมได้ เปิดดูแบบ AR บนโทรศัพท์ และฟังเสียงบรรยาย
- ค้นหาชิ้นงานข้ามทุกแหล่งเรียนรู้
- รองรับหน้าจอโทรศัพท์เป็นหลัก และแจ้งเตือนเมื่อเปิดผ่านเบราว์เซอร์ในแอป LINE หรือ Facebook

**สำหรับผู้ดูแลระบบ** (`/admin`)
- จัดการข้อมูลแหล่งเรียนรู้ หมวดหมู่ และชิ้นงาน พร้อมอัปโหลดโมเดล รูปภาพ เสียง และวิดีทัศน์
- จัดการบัญชีผู้ดูแลระบบ และดูบันทึกการแก้ไข
- ดูสถิติการเข้าชมรายแหล่ง รายชิ้นงาน และรายวัน โดยไม่เก็บข้อมูลส่วนบุคคลของผู้เข้าชม

## โครงสร้าง

```
├── deploy/     ชุดติดตั้งด้วย Docker Compose และคู่มือติดตั้งสำหรับเจ้าหน้าที่ IT
└── web/        ซอร์สโค้ดเว็บแอปพลิเคชัน (Next.js + MariaDB)
```

ระบบทำงานทั้งหมดภายใน Docker Compose ประกอบด้วย 3 บริการ ได้แก่ เว็บแอปพลิเคชัน ฐานข้อมูล MariaDB และบริการสำรองข้อมูลรายวัน (มี phpMyAdmin สำหรับงานดูแลรักษาให้เปิดใช้เมื่อจำเป็น)

## การติดตั้ง

ดูขั้นตอนทั้งหมดได้ที่ **[deploy/README.md](deploy/README.md)** โดยสรุปดังนี้

1. เครื่องเซิร์ฟเวอร์ต้องมี Docker Engine และ Docker Compose v2, RAM อย่างน้อย 2 GB, พื้นที่ดิสก์ว่างอย่างน้อย 20 GB
2. โคลน repository นี้ ตั้งค่าไฟล์ `deploy/.env` แล้วสั่ง `docker compose up -d --build`
3. นำเข้าชุดข้อมูลเริ่มต้น (ส่งแยกต่างหาก) ด้วย `sh import-bundle.sh`
4. สร้างบัญชีผู้ดูแลระบบคนแรก
5. ตั้งค่าโดเมน HTTPS และ reverse proxy (ระบบ AR บนโทรศัพท์ทำงานได้เฉพาะผ่าน HTTPS)

## ชุดข้อมูลเริ่มต้น

ข้อมูลเนื้อหาและไฟล์สื่อไม่ได้เก็บไว้ใน repository นี้ จะส่งมอบแยกเป็น 3 ไฟล์

| ไฟล์ | เนื้อหา |
|---|---|
| `allar_db.sql.gz` | ฐานข้อมูลเนื้อหา (ไม่มีบัญชีผู้ดูแลระบบ) |
| `uploads.zip` | โมเดล 3 มิติ รูปภาพ เสียงบรรยาย และวิดีทัศน์ |
| `SHA256SUMS.txt` | ค่าตรวจสอบความถูกต้องของไฟล์ทั้งสอง |
