## 1. โฟลเดอร์นี้คืออะไร

โฟลเดอร์นี้เป็น **ต้นแบบดีไซน์แบบ HTML/CSS ล้วน** ของเว็บ "คลังภูมิปัญญาชุมชน 3D/AR: 5 แหล่งเรียนรู้สำคัญ จังหวัดสกลนคร"
โครงการของสถาบันภาษา ศิลปะและวัฒนธรรม มหาวิทยาลัยราชภัฏสกลนคร

**เว็บจริงไม่ได้รันจากโฟลเดอร์นี้** เว็บจริงอยู่ในโฟลเดอร์ `web/` ของ repo เดียวกัน
- เป็น Next.js 16 + ฐานข้อมูล MariaDB ติดตั้งด้วย Docker Compose และส่งมอบให้ สวท. นำขึ้นเซิร์ฟเวอร์มหาวิทยาลัย
- ข้อมูลทั้งหมดบนเว็บจริง (ชุมชน หมวดหมู่ ชิ้นงาน ข่าว แกลเลอรี) มาจากฐานข้อมูล แอดมินกรอกผ่านหน้า `/admin`

**หน้าที่ของโฟลเดอร์นี้:** เป็นที่ออกแบบหน้าตา ทีมพัฒนาจะนำดีไซน์ที่นี่ไปใส่ในเว็บจริง

## 2. ดีไซน์จากที่นี่ไปอยู่ตรงไหนในเว็บจริง

เว็บจริงนำ CSS ของที่นี่ไปใช้ **เกือบตรงตัว** แล้วเขียน HTML เป็น React โดยใช้ **ชื่อ class เดิม**

| ไฟล์ที่นี่ | ในเว็บจริง (repo allAR) |
| :--- | :--- |
| `style.css` | `web/src/app/(site)/heritage.css` |
| `community.css` + `*-theme.css` | `web/src/app/(site)/community.css` (selector `.theme-x` เปลี่ยนเป็น `[data-theme='x']`) |
| `cover.css` | `web/src/app/(site)/cover.css` |
| `index.html` | หน้าแรก `web/src/app/(site)/page.tsx` + `components/WelcomeCover.tsx` |
| `<ชุมชน>.html` | หน้าเดียวใช้ร่วมกัน `web/src/app/(site)/c/[slug]/page.tsx` เปลี่ยนธีมตาม `data-theme` |
| `assets/*` (โลโก้ ลาย ภาพปก) | `web/public/brand/*` (ภาพใหญ่แปลงเป็น .webp) |

**กติกาเพื่อให้นำไปใช้ได้ง่าย**
1. **อย่าเปลี่ยนชื่อ class ที่มีอยู่แล้ว** ถ้าจะเพิ่มของใหม่ ให้เพิ่ม class ใหม่แทน
2. ธีมของแต่ละแหล่งเขียนเป็น `.theme-<slug> ...` ในไฟล์ `<slug>-theme.css` ใช้ slug ตามตารางข้อ 3
3. ทุกหน้าชุมชนต้องใช้ **โครงเดียวกัน** (hero → เรื่องราว → ที่ตั้ง → ข่าว → หมวดหมู่โมเดล) ต่างกันได้แค่ธีม เพราะเว็บจริงมีหน้าชุมชนหน้าเดียว
4. ไฟล์ข้อความภาษาไทยบันทึกเป็น **UTF-8** เท่านั้น
5. ภาพ ลาย และโลโก้ ใส่ใน `assets/` ภาพใหญ่ควรไม่เกิน 1–2 MB

## 4. ข้อมูลโมเดลและเนื้อหา: ไม่ต้องใส่ที่นี่

- ไฟล์ `phuphan-models.js` และ `nonhom-models.js` **ใช้สาธิตในต้นแบบเท่านั้น** ไฟล์โมเดลใน `assets/nonhom/models/` (743 MB) **ไม่ได้อยู่ใน GitHub** เพราะใหญ่เกิน ตอนเปิดต้นแบบ popup ของโนนหอมจึงโหลดโมเดลไม่ได้ ถือเป็นเรื่องปกติ
- เว็บจริงมีโมเดลชุดเดียวกันอยู่ในฐานข้อมูลแล้ว ได้แก่ ภูพาน 41 ชิ้น, โนนหอม 21 ชิ้น, วัดกลางฯ 29 ชิ้น และวัดมหาพรหมฯ 24 ชิ้น (2 วัดนี้ยังเป็นภาพถ่าย รอไฟล์โมเดล)
- ข้อมูลใหม่จากทีมลงพื้นที่ ส่งทาง Google Drive โฟลเดอร์ "รวมARพิพิธภัณฑ์" ในโฟลเดอร์ของแต่ละแหล่งเรียนรู้ โดยกรอก Google Sheet "แบบฟอร์มส่งข้อมูล" และรับเฉพาะไฟล์โมเดล `.glb` **ห้ามส่งไฟล์ .apk / Unity**
- ถ้าจะสาธิตหน้าตาด้วยข้อมูลตัวอย่าง ทำได้ แต่ห้ามถือว่าข้อมูลในไฟล์ `*-models.js` เป็นข้อมูลจริง

## 5. สิ่งที่ตัดสินใจไว้แล้ว (อย่าทำซ้ำหรือเปลี่ยนเอง ถ้าจะเปลี่ยนให้ถามเจ้าของโครงการก่อน)

- **กดการ์ดโมเดลแล้วไปหน้าชิ้นงานแยก** ไม่ใช้ popup
  - หน้าชิ้นงานในเว็บจริงมีตัวดู 3D, ปุ่ม AR, เสียงบรรยาย, คำอธิบายเต็ม และลิงก์แชร์ได้
  - เว็บจริงจึงไม่ได้นำ popup (`nonhom-model-viewer.js`, `three-model-viewer.js`) ไปใช้
- **ตัวดู 3D ในเว็บจริงใช้ `@google/model-viewer`** ติดตั้งไว้ในเครื่อง ไม่โหลดจาก CDN
  - ไม่ใช้ three.js แยก
  - ไอคอน Font Awesome และฟอนต์ Prompt / Space Grotesk ก็โหลดจากในเครื่องเหมือนกัน
- ส่วน "หน่วยงานร่วมขับเคลื่อน" ในหน้าแรกยังรอยืนยันว่าเป็นข้อมูลจริงหรือไม่ **อย่าใส่รายชื่อบุคคลเพิ่ม** จนกว่าจะได้รับอนุญาต
- ห้ามใช้อีเมลตัวอย่าง `example.ac.th` ช่องทางติดต่อใช้ของมหาวิทยาลัย

## 6. อัปเดตดีไซน์แล้ว ต้องทำอะไรต่อ

1. Fork repo แล้วสร้าง branch เช่น `design/<เรื่องที่แก้>` จากนั้นแก้ไฟล์ในโฟลเดอร์นี้
2. เปิดดูด้วย `เปิดเว็บไซต์.cmd` (Windows) หรือ `python start-website.py`
3. เพิ่มบรรทัดในหัวข้อ 7 ว่าแก้ไฟล์ไหน อะไร วันที่เท่าไร
4. เปิด Pull Request เข้า `main` แล้วส่ง prompt ส่งงานตามรูปแบบใน `docs/team/AI-GUIDE.md` ให้หัวหน้าโครงการ
